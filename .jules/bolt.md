## 2024-10-24 - [Optimize JSON validation]
**Learning:** When optimizing JSON validation, use a 'try-parse first' strategy instead of blanket string replacements (e.g., replacing single quotes with double quotes) before parsing. This prevents corrupting valid JSON that legitimately contains the replaced characters and avoids performance overhead on the happy path.
**Action:** Always attempt to parse the original string first. Only fallback to quote replacement and a second parse attempt if the initial parse fails and single quotes are actually present in the string.
## 2023-10-27 - O(N) sequential awaits in FunctionGroup evaluation
**Learning:** Found an architectural bottleneck where the `FunctionGroup` accessor methods (`_get_all_but_excluded_functions`, `get_excluded_functions`, `get_included_functions`, `get_all_functions`) evaluated `await self._fn_should_be_included(name)` sequentially in a tight loop across all candidates. This linear blocking behavior can stall the event loop when processing large groups of dynamic tools that require I/O or delays in their inclusion callbacks.
**Action:** When filtering a sequence or mapping where the filter condition is an `async` function, use `asyncio.gather` on a pre-filtered list of candidates instead of sequential `await` checks inside a loop to parallelize the check and transform O(N) linear time blocking into O(1) concurrent execution time.
