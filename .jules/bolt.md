## 2024-10-24 - [Optimize JSON validation]
**Learning:** When optimizing JSON validation, use a 'try-parse first' strategy instead of blanket string replacements (e.g., replacing single quotes with double quotes) before parsing. This prevents corrupting valid JSON that legitimately contains the replaced characters and avoids performance overhead on the happy path.
**Action:** Always attempt to parse the original string first. Only fallback to quote replacement and a second parse attempt if the initial parse fails and single quotes are actually present in the string.
## 2024-10-25 - [Optimize regex parsing in ReAct Agent]
**Learning:** Python's `re` module internally caches recently compiled regular expressions. However, calling `re.search()` with a string pattern inside frequently executed functions (like an output parser evaluating LLM streams) still incurs function call overhead and a cache lookup. Moving `re.compile()` to the module level and storing the compiled regex as a constant eliminates this overhead and can improve execution time by 15-40% for string matching operations.
**Action:** When a static regex pattern is used inside a class method or function that is called repeatedly, pre-compile it at the module level using `re.compile()` and call `.search()` or `.match()` on the compiled object instead of using the dynamic `re.search(pattern, ...)` method.
