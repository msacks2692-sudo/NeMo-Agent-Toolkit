## 2025-04-12 - Prevent Argument Injection in Subprocess Calls
**Vulnerability:** Argument injection vulnerabilities (e.g., flag injection) were found across multiple registry handlers (`pypi_handler.py`, `rest_handler.py`, `local_handler.py`). Dynamically generated values like package names or paths were passed to `subprocess.run` directly after the base command (e.g., `uv pip install <package_name>`).
**Learning:** If a dynamic value (like a package name or file path) starts with a hyphen (`-`), the underlying CLI tool (like `pip`, `uv`, or `twine`) might interpret it as a command-line flag rather than a positional argument, leading to unexpected behavior or security issues. Furthermore, in one instance, a list of packages was joined by spaces into a single string argument, breaking `uv pip install`.
**Prevention:** Always use `--` to explicitly signal the end of command-line options before passing untrusted or dynamic positional arguments (e.g., `uv pip install -- <package_name>`). Additionally, always pass multiple arguments to `subprocess.run` as separate list elements using `cmd.extend(packages)`, rather than joining them into a single space-separated string.
