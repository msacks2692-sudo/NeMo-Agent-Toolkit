
## 2025-02-14 - Fix Path Traversal in REST Handler File Sink
**Vulnerability:** A Path Traversal vulnerability existed in `src/nat/registry_handlers/rest/rest_handler.py`. The `rest_handler` received a `validated_pull_response` containing packages, and directly used `package.whl_name` (which could be controlled by a malicious remote registry) by joining it with a `tmp_dir` path to create the file path for writing the downloaded wheel bytes (`with open(whl_path, "wb") as f:`).
**Learning:** This vulnerability existed because the filename originating from an external network source was implicitly trusted and not sanitized before being utilized in file I/O operations. A malicious registry could supply a name like `../../../../etc/passwd` to execute an arbitrary file write outside the designated temporary directory, potentially overwriting critical system files.
**Prevention:** To avoid this in the future, whenever dealing with filenames sourced from external inputs (especially file uploads, network responses, or compressed archives), always sanitize the filename using `os.path.basename()` before appending it to a base directory using `os.path.join()`. This ensures any malicious directory traversal components (like `../`) are stripped out.
