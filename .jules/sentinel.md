## 2025-04-08 - [Argument Injection in subprocess.run]
**Vulnerability:** Argument injection and improper argument splitting when dynamically passing package arrays or query strings to CLI commands via `subprocess.run` without `shell=True`. Specifically, joining an array into a single space-separated string incorrectly feeds it as one monolithic argument to the subprocess, which fails functionality and can be exploited. Furthermore, starting parameters with a hyphen can cause argument injection to external CLIs like `pip`, `twine`, or `uv`.
**Learning:** Even without `shell=True`, passing dynamic input directly into a command list can lead to argument injection if the input starts with a `-` or `--`. Also, `subprocess.run` expects arrays of strings to represent separate arguments.
**Prevention:** Always use `--` in the command list to mark the end of options before appending dynamic arguments. Always extend the argument list with the individual array elements directly instead of joining them into a string.
