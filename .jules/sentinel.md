## 2026-04-15 - Prevent Path Traversal in Rest Handler Downloads\n**Vulnerability:** Found a critical path traversal vulnerability (Zip Slip variant) in `src/nat/registry_handlers/rest/rest_handler.py` where untrusted package filenames downloaded from a remote registry via a REST payload were directly concatenated with a target directory path using `os.path.join()` without sanitization.\n**Learning:** Trusting remote filenames (e.g., `package.whl_name`) in file I/O operations exposes the host system to arbitrary file overwrites if the server is compromised or returns malicious payloads (e.g., `../../../../etc/passwd`). The `os.path.join()` function will traverse upwards if absolute paths or `..` sequences are passed.\n**Prevention:** Always sanitize any filename provided by user input or external systems using `os.path.basename()` before appending it to a destination path.
