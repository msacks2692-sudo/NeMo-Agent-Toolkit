## 2026-06-21 - Path Traversal bypass with os.path.normpath
**Vulnerability:** A path traversal vulnerability existed in the static file routes where `os.path.normpath(path.strip("/"))` was used as the sole sanitization mechanism. This allowed paths like `%2F..%2F..%2Fetc%2Fpasswd` to resolve as `../etc/passwd` because `normpath` does not prevent leading `..` components from escaping the base directory.
**Learning:** `os.path.normpath` is not a complete path sanitization function on its own when dealing with user input because it resolves `..` components but will leave them in the path if they traverse above the root of the provided string. Relying solely on it can expose the system to arbitrary file reads/writes if the path is appended to a base directory.
**Prevention:** Always follow `os.path.normpath` with explicit checks to ensure the resulting path does not start with `..` and does not contain `..` parts (e.g., `if sanitized_path.startswith("..") or ".." in sanitized_path.split(os.sep): raise Error()`).
