## 2025-02-14 - Path Traversal and Argument Injection in Subprocesses
**Vulnerability:** Found a Path Traversal vulnerability in `rest_handler.py` where a user-provided `whl_name` was directly joined with `os.path.join`, allowing arbitrary file writes. Additionally, found multiple Argument/Command Injection vulnerabilities in both `rest_handler.py` and `pypi_handler.py` where user-controlled string inputs (like package paths and search queries) were passed un-terminated into `subprocess.run` command lists.
**Learning:** Even when passing arguments as a list to `subprocess.run` (avoiding `shell=True`), vulnerabilities still exist if arguments begin with hyphens (Argument Injection) or if dynamically populated lists are `.join()`'d back into strings before execution.
**Prevention:** Always sanitize dynamically constructed file paths using `os.path.basename` when writing files based on remote input. For `subprocess.run`, always construct the command logically as a list, and enforce safety by prepending `--` before user-provided arguments to signal the end of command-line options.
