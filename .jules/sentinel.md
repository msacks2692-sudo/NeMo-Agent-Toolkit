## 2025-05-18 - Argument Injection in Subprocess Commands
**Vulnerability:** Argument injection vulnerabilities existed in multiple registry handlers (`pypi_handler`, `local_handler`, `rest_handler`) and CLI commands where user-controlled inputs (like package names or query strings) were passed as elements in `subprocess.run(..., shell=False)` lists without being prefixed by `--`.
**Learning:** Even when `shell=False` is used, passing external input to CLI tools (like `pip`, `twine`, or `uv`) can lead to argument injection if the input starts with a hyphen (`-`). Tools parse these inputs as flags or options, potentially leading to unintended behavior (e.g., overriding index URLs or executing arbitrary actions supported by the tool).
**Prevention:** Always insert the double-dash `--` argument delimiter before passing dynamic variables as positional arguments to CLI tools in `subprocess.run` lists. This explicitly signals to the parser that subsequent items are positional data, not options.
