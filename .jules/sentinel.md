## $(date +%Y-%m-%d) - [CRITICAL] Prevent Argument Injection in Subprocess Calls
**Vulnerability:** Argument Injection vulnerability in `subprocess.run` calls in `PypiRegistryHandler` and `RestRegistryHandler`. User-supplied values (like package paths or search queries) were appended directly to command lists. If these values started with a hyphen (`-`), the command-line tool (like `twine` or `pip`) could mistakenly parse them as malicious options/flags instead of positional arguments.
**Learning:** Argument injection can occur even when `shell=False` in `subprocess.run`, since passing arguments that start with `-` modifies how the invoked CLI interprets the command. Additionally, when using `subprocess.run` without `shell=True`, multiple arguments must be passed as distinct elements in the list (e.g., using `cmd.extend()`), rather than joining them into a single string.
**Prevention:** Always use the POSIX standard `--` delimiter in command arrays before inserting variable arguments. This signals to the command parser that all subsequent arguments should be treated as positional arguments, neutralizing any injected flags.
